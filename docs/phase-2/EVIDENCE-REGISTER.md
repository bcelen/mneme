# Primary-Evidence Register

**Status:** Accepted
**Review date:** 2026-09-17
**Evidence cutoff and retrieval date:** 2026-09-17
**Method:** Official specifications, maintainer documentation, project repositories, license texts, support policies, and accepted Mneme requirements. No software was installed and no prototype or acceptance test was run.

## Reading the register

- **High** confidence means the source directly establishes the narrow documentary claim.
- **Medium** means the source establishes capability but Mneme-specific satisfaction is an architectural inference.
- **Low** means material behavior, workload fit, or operational cost remains untested.
- A documented capability is not evidence that Mneme's implementation tests pass.
- Versions and policies are time-sensitive and must be rechecked before ADR acceptance and implementation.

## Evidence synthesis

- The evidence establishes feasible implementation paths for all four candidates; it does not establish that any candidate has passed the synthetic corpus or acceptance-test matrix.
- PostgreSQL offers documented linguistic configuration and operational recovery breadth. SQLite offers a smaller operating surface and credible FTS/backup mechanisms, but its concurrency boundary is material.
- SwiftUI has the strongest documented path to Apple-native interaction. Web/PWA candidates have the smallest distribution burden. Flutter offers code reuse but not automatic Apple-platform fidelity.
- All named direct components use permissive or public-domain terms. Transitive dependencies, parsers, extractors, OCR, models, build inputs, and Apple distribution terms still require a versioned inventory before G-09 can receive implementation acceptance.
